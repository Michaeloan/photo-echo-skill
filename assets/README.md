# 真实照片与成品示例

本目录展示维护者授权用于本仓库的七张真实九寨沟照片及已确认的Live手帐成品。照片、插画与视频保留相应素材权利；允许随本skill下载并在本机复现效果。单独转载、再分发或作为商业素材使用，请先取得相应授权。本目录素材不适用代码的MIT授权。

每个 examples 子目录包括：

- source.jpg：原照片的转正公开缩图，最长边1920；EXIF等元数据已移除。
- source-display.jpg：原成品上半幅实际显示区域。
- reference.jpg：原插画实际取景的公开缩图。
- illustration.png：原成品使用的插画图层。
- cover.jpg、preview.mp4：真实手帐封面和视频；植物小岛已更新连续运动，其余六张沿用原确认版本，均未重新生图。
- selection.json、motion.json：相对源图与插画资产的两个独立坐标系。
- report.json：去除本机路径后的取景、构图和电脑检查记录。
- motion.gif：部分作品附带，从同一MP4下半幅生成的微动预览。
- handbook.png、handbook-layout.json：复用同一公开原图与插画生成的新版静态手帐，完整原图、自由比例与英文配文；没有重新生图。

`static-gallery.jpg` 展示这七张新的完整原图静态成品。此前的封面、视频和GIF是历史动态演示，保留供运动效果对照；它们的固定裁切版式不代表当前默认排版。新增图片没有引入私人批次素材，原图与插画保持不变。

selection 的源图归一化坐标也适用于转正后等比缩小的 source.jpg。公开参考缩图与重新裁取的参考可能因取整、JPEG编码略有不同，不能据此宣称原始逐像素复现。

七张配对资源已在电脑做元数据检查，phone_verified 保持 false；本目录不包含原始EXIF、账号、私有桌面项目和Apple配对二进制。可用公开素材通过 --apple 在本机重新生成配对资源。
