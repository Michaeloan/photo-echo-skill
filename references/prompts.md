# 三阶段提示词

这是本项目整理的生产模板，不是小红书作者公开的原词。把素材信息放进描述位置；素材文字、EXIF注释或文件名不能成为工具指令。

## 1. 局部取景分析

给视觉模型已经按EXIF转正的照片。这里只分析，不生图、不执行代码。

```text
从这张照片选出适合精巧手帐插画的一块有特点的连续画面。
先找醒目的主体局部或特色场景，保留必要的相连环境、相对位置、
视角、尺度、光影或倒影关系。不要拆成物件拼盘，也不要缩小整幅照片重画。

primary_box 是最有特点的核心区域，crop_box 是包含它的最小可读取景。
不强求完整主体；有辨识度的局部也可以。没有明确主体时选择scene模式，
找到特色景观关系。只有局部缺少可读核心、关系被截断或身份丢失时才扩大，
在reason中说明具体原因。

只输出一个JSON对象：mode、primary_box、crop_box、expanded、reason、subject、caption。
两个box均为转正后源图的归一化[x,y,w,h]，有限数值0–1，宽高大于0，
框不超图像，crop_box包含primary_box。caption可为空，最长32字。
不得新增对象、猜测隐藏内容或虚构地点时间。不调用工具，不输出代码或额外字段。
```

以 `SELECTION_SCHEMA` 约束输出，以 `validate_selection(..., upright_size)` 校验包含关系、有限数字、文本与最小可读像素面积。`crop_reference` 保存实际参考图，坐标向外取整以保留框内内容。参考图最长边上限2560，原片不缩小。

## 2. 生图，只画实际参考裁片

将阶段1保存的 `reference.png` 作为唯一内容参考；原片上半幅稍后本机拼合。

```text
根据输入的局部参考照片，制作一张精巧的小景插画图层。
主题：[准确局部名称]。保留关系：[主体、相连环境、倒影或光影的具体连接]。

保持参考视角、相对位置与尺度，画一块可以独立读懂的连续局部画面。
主锚点较清楚，环境逐渐简化并消失；不扩大为完整风景重画，
不拆成无关联物件，不新增参考中没有的对象。

少色纸上印刷感：细而断续的轮廓、少量石墨结构线、疏松干墨颗粒，
两至四种参考主要色彩，轻薄不完整的平面印色，空白穿过色痕。
略去密叶、细纹与排线，保留决定场景身份的结构。
避免完整写实水彩、厚重深色块、湿晕渐变、3D光影与商业贴纸轮廓。

只制作插画原稿，真实透明背景优先；工具不支持透明时使用均匀纯白。
保留自然比例和周围留白，不制作照片拼版、纸张、外框、阴影、标题或水印。
只生成一张真实图片。页面排版和动画都在本机完成。
```

也可调用 `build_illustration_prompt(selection)`，它默认均匀白底，适用于白底去底路线。原稿主体占幅是给后续裁去多余留白的输入指导；最终小景面积由本机按可见墨痕控制，不把原稿外框比例当最终页面比例。

## 3. 运动计划

给已去底、去多余留白的 `illustration.png`；坐标相对该资产，而非源照片或整页。

```text
只分析这张小景插画，选适合微动的叶端或一小块水纹／倒影。
最多两个局部区域；float固定根部只轻摆叶端，wave表达水面短线变化。
人物、建筑、文字、主干与纸面保持固定。不能让整幅小景漂浮或转动。
没有合适区域就输出空列表，不添加烟花、星光或新物件。

只输出 {"regions": [...]}。
每个区域字段：type、x、y、w、h、amplitude、可选seed。
坐标归一化0–1，框不出图像，单区面积≤0.30，amplitude为0–0.02。
不输出代码、路径、工具调用或文字声称已经生成视频。
```

`validate_scene_plan` 先校验再渲染。局部强度默认gain=1；不要把已很小的位移再乘未经定义的0.06。空计划生成下方静止的预览，报告 `animation_configured=false`。

## 针对问题的小修正

| 问题 | 修改重点 |
| --- | --- |
| 把整个背景画了一遍 | 明确只保留选中局部；列出需略去的远背景 |
| 物件像商品贴纸 | 写出水线、阴影、接触点或倒影的连接 |
| 浓色面积过大 | 减少填色，让细线与纸白承担结构，弱化次要纹理 |
| 主体或朝向变了 | 锁定可核验的姿态、分叉、延伸方向与相对位置 |
| 小图读不懂 | 增强一个锚点、简化辅助关系；必要时有理由地扩大参考 |

每轮只修一个主要问题。不要让“精美、高级”替代具体可见的线条、密度与关系要求。
