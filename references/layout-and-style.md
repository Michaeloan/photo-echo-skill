# 小景的尺度、关系与排版

这些数值定义默认风格，不取代用户明确指定的版式。源图比例、主体分布与墨色密度，都影响实际放置。

## 层级与默认值

| 层 | 默认处理 | 检查方法 |
| --- | --- | --- |
| 整体 | 1080×1440，上下各半 | 接缝在y=720，没有额外分隔带 |
| 原片 | 上半铺满、等比适配 | 照片四边接触上半幅四边，无纸框、无拉伸 |
| 纸面 | 只在下半，近白、极轻固定颗粒 | 不盖住上半照片，也不随动画移动 |
| 小景 | 初始宽≤43%整幅宽、高≤42%下半高 | 看可见墨痕范围，不用透明外框充当面积 |
| 浓度 | 墨色加权面积初始≤上半面积的4.5% | 密实图案进一步缩小；是布局启发值，不是审美评分 |
| 调整 | 大小系数0.7–1.3 | 安全界限：宽≤64%整幅宽、高≤60%下半高 |
| 位置 | 下半垂直重心约55%，横向锚点38%–62% | 光学重心对齐，保留呼吸与标题距离 |
| 文字 | 可选单行，默认18px左右 | 次要层级，无虚构日期地点；未要求时可为空 |

上限不是目标面积。枝条、沉木、倒影等小景可以明显更小；浓色、复杂构图尤其需要收缩。只有缩小后的主体确实难辨认时，才适度扩大或减少线条。

## 两种裁切各自做什么

**插画取景**回答“画哪块有特点的画面”。它可以小而紧凑，需要保留可读的连接关系。参考裁片用于生图。

**原片展示裁切**回答“原照片如何装进上半窗口”。它只在本机进行；竖片等比裁入横向窗口，焦点由主体中心建议，用户可调整。照片文件完整保留，显示区域由本机重采样，不能说竖片所有像素都出现在成图上。

3:2横向输入完整填入1080×720。其他比例按窗口等比裁入，不能拉长人物、山脊或建筑。

## 取景决策示例

| 照片特征 | 合理局部 | 扩大条件 |
| --- | --- | --- |
| 水中突出的小树 | 树的特征部分＋树根或小岛＋直接倒影 | 倒影与水线关系被切断时扩大一点 |
| 近处横卧的木枝 | 分叉端＋周围水光或地形 | 只剩无法识别的线时保留连接环境 |
| 船靠岸 | 船的特色局部＋水线或绳索关系 | 船与岸的空间关系丢失时扩大 |
| 建筑局部 | 屋檐、窗、台阶与相邻结构 | 特征过于通用或透视不成立时扩大 |
| 无明显主体的远景 | 山脊交叠、岸湾转折或云影局部 | 最小局部不能读懂时逐渐扩大，可能到较大场景 |

不能用孤立叶片替代独特的枝条与水面关系，也不能因为没有“物件”就立即重画整幅风景。景观关系本身可以是主体。

## 画法与质量修正

保留较准确的主锚点与两三处必要连接，把次要細纹省略为断线、少量干色与空白。两至四种**主要色彩**来自源图；抗锯齿与颗粒的像素颜色不必硬量化为两至四个RGB值。

结果过满：先减少次要轮廓、叶簇和密排线，再降低色块面积，最后调整可见小景尺度。整幅缩小不能修复内容选择。

结果像贴纸：保留连续水面、相接阴影或共同透视，让次要位置的边缘断开；避免厚描边与封闭白色外轮廓。

结果不精细：提高主锚点结构线的准确性，减少同等重要的细节；不要用高密度纹理弥补空间关系错误。

底色处理优先保留真实alpha。均匀纯白原稿可用 `prepare_scene` 保守去除与图边连通的背景；有色、有纹理或像照片的背景会被拒绝。保留原稿并修正生成结果，不用硬阈值抹去浅细线。
