# 完整原图、自由比例与小景留白

照片和插画各自等比缩放。原照片完整显示，插画取景只是生图参考；这两件事不能混用。

## 画布跟随照片

默认照片宽度1080像素，照片区高度由转正后原图比例计算。下方纸面高度默认约为画布宽度的三分之二，可以调节；照片区与纸面不固定各占一半，也不强制3:4或其他预设比例。

横片、方片、竖片、全景分别得到不同的整体长宽比。特别狭长的原图通过等比适配完整显示。编码尺寸取整或缩小不裁掉原图四边。用户明确要求裁切或历史固定版式时才用 `legacy-crop`，不能因为旧作品曾经裁切就继续照搬。

用户明确指定宽高时，可设置 `--width` 与 `--height`，照片仍完整等比适配该画布；只提供宽度时高度自动变化。重排早期固定裁切作品默认恢复自动高度，用户明确设置的完整原图画布尺寸则逐张保留。

| 调整项 | 默认做法 |
| --- | --- |
| 照片 | 完整原图，EXIF转正、等比缩放 |
| 插画区高度 | `paper_ratio`，相对画布宽度，可单张或整批改 |
| 小景大小 | `scale`，默认1；密实图案自动收缩 |
| 文字 | 可选一行简短英文，也可留空 |
| 输出 | 默认静态PNG；可选JPG、完整手帐或单独插画 |
| 已有作品 | 使用原图与已生成插画，在本机重排 |

小景初始宽约不超过整幅宽的43%、高约不超过纸面高的42%，只是默认视觉起点，不是必须达到的尺寸。通过可见墨痕的重心放置，密实图案进一步缩小；用户可调节大小和留白。脚本的大图资源上限和图层边界保护不应被描述为固定构图要求。

## 原照片与插画参考

插画参考回答“画哪块有特点的画面”：可以小而紧凑，保留可读的相连环境、视角和光影。它只供生图工具制作下方小景。

照片区域回答“如何保留整张原照片”：使用完整转正原图，没有按参考选区或固定窗口删去边缘。原图文件、完整成图和局部参考分别保留，不能把裁片当成原图。

## 已有批次如何调整

先找到源照片与插画的对应关系。对本skill已完成的目录，`recompose` 自动读取内部素材快照与每张最后成功的设置；原输入移走后也可复用已保存的源图和插画。

只改用户指定的参数：改纸面高度不改插画内容；改大小不复制另一张蒙版；改配文不重新生图。批量默认保留各张的独立设置，可只选部分作品。参数变化后应重新合成并查看实际成图，新版本追加保存，旧图保留。

已有中文配文可以根据保存的取景说明准确写成短英文；无法可靠表达时留空。默认渲染器排除旧的非英文配文，用户明确选择其他语言时可用 `--caption-language original`，再按该语言提供字体。

## 小景质量

保留较准确的主锚点与两三处必要连接，把次要纹理省略为断线、少量干色与空白。两至四种主要色彩来自源图，不对抗锯齿和颗粒硬量化。

| 问题 | 修正重点 |
| --- | --- |
| 太满 | 减少次要轮廓、密排线和色块，再调整大小 |
| 像贴纸 | 保留水线、接触阴影、共同透视等连接关系 |
| 结构不清 | 增强一个主锚点，不用高密度纹理掩盖关系错误 |
| 参考太小 | 只在身份或关系不完整时逐渐扩大 |

保留真实alpha；均匀纯白原稿可保守去底。底色不均匀或像照片时保留原稿并检查，不用硬阈值抹掉浅线。旧运动计划不影响静态成图，不把缺少视频当作不能调整已有插画的理由。
