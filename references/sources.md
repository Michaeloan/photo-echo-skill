# 公开示例与方法参考

## 本仓库示例

README全部成品来自维护者明确指定并授权公开的七张真实九寨沟照片手帐。直接复用用户确认版本，原插画由实际可用的Luna与生图工具制作，动画和封装在本机完成；此次发布云端生成调用为0。

公开原片与参考图等比缩小、转正并移除EXIF。插画、封面和视频来自对应成品；GIF取自同一MP4下半区域。公开记录去除源盘路径、账号与桌面项目状态。源图选区来自这些成品的已有选择记录，不作为全自动取景准确率评测。

主模板来自用户多轮审美反馈：保留特色局部的连续关系、小尺度而精巧、照片铺满与纸面分层、运动局限局部。提示词、排版和本机助手为本仓库整理的实现。
