# 公开示例与方法参考

## 本仓库示例

README全部示例沿用本仓库已有的七张真实九寨沟公开照片与原插画。新的静态手帐改为完整原图、自由比例与英文配文，本机重新排版，新增生图调用为0。历史封面、MP4与GIF保留供动态对照；植物小岛的历史运动为连续水纹与叶端轻摆。没有新增维护者私人批次照片。

公开原片与参考图等比缩小、转正并移除EXIF。插画、封面和视频来自对应成品；GIF取自同一MP4下半区域。公开记录去除源盘路径、账号与桌面项目状态。源图选区来自这些成品的已有选择记录，不作为全自动取景准确率评测。

主模板来自用户多轮审美反馈：保留特色局部的连续关系、完整原照片与自由比例、小尺度而精巧、英文配文、批量静态输出与已有插画复用；动态仅为可选功能。提示词、排版和本机助手为本仓库整理的实现。
